# AGENTS.md

## Project Intent

WareFlow should feel like a real internal logistics product. Keep changes production-minded: typed contracts, clear domain names, useful tests, and a focused operations dashboard.

## Conventions

- Backend packages live under `com.wareflow`.
- Keep controller, service, repository, dto, entity, security, event, config, and exception layers separate.
- Frontend feature code lives under `src/features`.
- Prefer status badges, compact tables, and scan-friendly dashboard controls.
- Do not add paid AI dependencies for Risk Radar; keep the first version rule-based.
